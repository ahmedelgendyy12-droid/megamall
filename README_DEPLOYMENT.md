# نظام إدارة ومتابعة مبيعات وأقساط ميجا مول (تحالف الشركات الأربعة)
Mega Mall Installment & Sales Management System

نظام متكامل صُمم خصيصاً لإدارة ومتابعة مبيعات وأقساط مشروع **ميجا مول (Mega Mall)** الناتج عن تحالف 4 شركات شريكة:
1. **شركة كونكريت (Connect / CRD)**
2. **شركة ترست (Trust)**
3. **شركة إم إم دي (MMD)**
4. **شركة تي دي (TD)**

---

## 🚀 طريقة التشغيل على جهازك (أسهل طريقة)

1. اضغط دبل كليك على ملف:
   ```
   start.bat
   ```
   أو من سطر الأوامر:
   ```bash
   python run_app.py
   ```
2. سيفتح المتصفح تلقائياً على الرابط:
   ```
   http://localhost:8000
   ```

## 🌐 طريقة الرفع المجاني على الإنترنت (PythonAnywhere)
لكي تتمكن جميع الشركات من فتح الموقع من هواتفهم وأجهزتهم بأمان ومجاناً 100%:

### الخطوة 1: عمل حساب مجاني
1. ادخل على موقع [pythonanywhere.com](https://www.pythonanywhere.com) واضغط **Sign up for free**.
2. اختر اسم مستخدم (سيكون هو رابط موقعك، مثلاً: `megamall2026.pythonanywhere.com`).

### الخطوة 2: رفع ملفات المشروع
من لوحة تحكم PythonAnywhere -> قسم **Files**:
ارفع الملفات الثلاثة الأساسية في مجلد حسابك:
- `server.py`
- `mega_mall.db`
- مجلد `templates/` وبداخله `index.html`

### الخطوة 3: إعداد وتشغيل الموقع (Web App)
1. ادخل على تبويب **Web** واضغط **Add a new web app**.
2. اختر **Manual configuration** ثم اختر **Python 3.10** أو **3.11**.
3. في ملف **WSGI configuration file**، اضغط على الرابط لتعديله، واكتب الكود التالي:
   ```python
   import sys
   import os
   path = '/home/YOUR_USERNAME' # استبدل باسم مستخدمك
   if path not in sys.path:
       sys.path.append(path)

   from a2wsgi import ASGIMiddleware
   from server import app
   application = ASGIMiddleware(app)
   ```
4. في قسم **Bash Console** ثبّت المكتبات بأمر واحد:
   ```bash
   pip install fastapi uvicorn a2wsgi openpyxl
   ```
5. اضغط زر **Reload** الأخضر في صفحة Web.
6. مبروك! الموقع متاح الآن برابطك المجاني مع شهادة أمان مشفرة HTTPS مجانية ومتاحة 24 ساعة لجميع الشركات!

## 📊 مميزات النظام

1. **Cards Center (مستوحى من Mophy)**:
   - 4 بطاقات بنكية رقمية بألوان كل شركة (كونكريت أزرق، ترست بنفسجي، MMD أخضر، TD برتقالي).
   - عرض فوري لإجمالي المبيعات، المحصل الفعلي، ونسبة التحصيل لكل شركة.
   - النقر على أي بطاقة يقوم بفلترة لوحة التحكم كاملة لتلك الشركة تلقائياً.

2. **لوحة مؤشرات مالية شاملة**:
   - إجمالي المبيعات المحققة مقابل أسعار الكتالوج والخصومات.
   - إجمالي المحصل الفعلي (وصل كام).
   - الأقساط القادمة المستحقة (المفروض يدخل كام).
   - الأقساط المتأخرة مع عداد تنبيه فوري ونبض تحذيري.
   - المتبقي الكلي للتحصيل (لسه هيدخل كام).

3. **رسوم بيانية تفاعلية**:
   - رسم بياني للتدفقات النقدية (Cash Flow Wave) يقارن المستحق المجدول بالمحصل الفعلي شهرياً وربع سنوياً.
   - دونات تشارت (Donut Chart) يوضح توزيع حصص الشركات ومبيعات الأدوار.

4. **إدارة وتحصيل الأقساط**:
   - فلترة ذكية: المتأخرات، المستحقة القادمة، المسددة.
   - زر سداد سريع يفتح نافذة تسجيل التحصيل وتوليد رقم إيصال فوري واختيار طريقة الدفع (شيك، تحويل، كاش).
   - كشف حساب كامل لكل وحدة وعقد مع شريط تقدم ونسبة التحصيل.

5. **تسجيل بيع وحدة جديدة**:
   - اختيار أي وحدة من الوحدات الـ 198 المتاحة بالمول.
   - جلب سعر الكتالوج والمواصفات وحساب الخصم الممنوح تلقائياً.
   - تحديد الدفعة المقدمة وجدولة الأقساط (شهري، ربع سنوي، سنوي) وحساب قيمة القسط تلقائياً.
   - تحويل حالة الوحدة فوراً من "متاحة" إلى "مباعة" وحفظ العقد.

6. **أمان كامل وصلاحيات محددة**:
   - تشفير كلمات المرور وجلسات مؤمنة.
   - نظام صلاحيات يضمن عدم وصول أي شركة لبيانات أو عملاء شركة أخرى، مع إشراف كامل للمدير العام.
