# 🏢 نظام إدارة ومتابعة مبيعات وأقساط ميجا مول (Mega Mall Management System)

نظام متكامل صُمم خصيصاً لإدارة ومتابعة مبيعات وأقساط مشروع **ميجا مول (Mega Mall)** الناتج عن تحالف الشركات الشريكة:
1. **شركة كونكريت (Connect / CRD)**
2. **شركة ترست (Trust)**
3. **شركة إم إم دي (MMD)**
4. **شركة تي دي (TD)**

---

## 👥 بيانات تسجيل الدخول الافتراضية

| الحساب | اسم المستخدم | كلمة المرور | الصلاحيات |
|---|---|---|---|
| **المدير العام (Admin)** | `admin` | `Adm$Dfm0379` | رؤية كاملة لكافة الشركات، سجل النشاطات، النسخ الاحتياطي، تعديل وحذف العقود |
| **شركة كونكريت (Concrete)** | `concrete` | `12341234` | وحدات ومبيعات وأقساط شركة كونكريت، تعديل وحذف عقودها الخاصة |
| **شركة ترست (Trust)** | `trust` | `Trs$jLP3211` | وحدات ومبيعات وأقساط شركة ترست، تعديل وحذف عقودها الخاصة |
| **شركة MMD** | `mmd` | `Mmd!iEg2427` | وحدات ومبيعات وأقساط شركة MMD، تعديل وحذف عقودها الخاصة |
| **شركة TD** | `td` | `Td!DOB0296` | وحدات ومبيعات وأقساط شركة TD، تعديل وحذف عقودها الخاصة |

---

## 🚀 التشغيل المحلي (Local Development)

```bash
# تثبيت المتطلبات
pip install -r requirements.txt

# تشغيل الخادم
python run_app.py
```
يفتح النظام تلقائياً على: `http://localhost:8000`
